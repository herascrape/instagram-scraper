# Security Policy

## Reporting a vulnerability

Email **support@herascrape.com** with a description of the issue and steps to
reproduce it. Please do not open a public issue for security reports.

We aim to acknowledge reports within 3 business days.

## Scope

This repository contains the instagram-scraper command-line tool and library.
Issues in the hosted herascrape API may be reported to the same address.

Never include live API keys in a report. Rotate any key you believe has been
exposed from your herascrape dashboard.
